<!-- ABOUT THE PROJECT -->
¡Bienvenido al repositorio de BonsaiPractice! Este proyecto es una landing page de práctica que recrea el diseño y contenido de un sitio web existente. El objetivo principal fue perfeccionar habilidades de maquetación, estructura y estilo visual sin incluir funcionalidades dinámicas.

* [![HTML5][HTML5.com]][HTML5-url]


### Instalacion y Uso

1. Clonacion del repositorio:
   ```sh
   git clone https://github.com/Jerimonski/Bonsai_Practice.git
   ```
3. Instalacion de los paquetes NPM
   ```sh
   npm install
   ```
4. Cambia el git remote url para evitar subir codigo erroneo al proyecto base:
   ```sh
   git remote set-url origin https://github.com/Jerimonski/Bonsai_Practice.git
   git remote -v # Para confirmar los cambios
   ```
